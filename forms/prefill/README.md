# Browser-compatible prefill sources

These five PDFs are non-encrypted copies of the matching official PDF source files one directory above. They exist because the official DMV source PDFs use legacy encryption that prevents reliable browser-side form editing.

The website uses these files only to create editable local drafts for:

- OL 12
- OL 21A
- OL 53
- ADM 9050
- the Thousand Oaks home business packet

Do not treat this folder as a replacement for the official source. Compare the generated draft with the matching official source before you complete, sign, notarize, or file it. Signatures, notary sections, surety content, personal identity fields, bank information, Live Scan fields, and official fields are deliberately left blank by the tool.
